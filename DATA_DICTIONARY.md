# Market observation data dictionary

The public collector output is `data/market_observations.json` (schema version 7). A record is one reported market observation, not necessarily one individual animal. The file also includes precomputed `benchmarks.groups`, generated by `scripts/market_model.py`; each benchmark group is isolated by state, Western aggregate, or named regional report, category, exact unit, source series, Corriente origin, reporting period, and weight cohort. Source-published weight ranges remain intact; observations with a reported average weight but no class range are assigned to a 100 lb cohort for like-for-like comparison.

## Core fields

| Field | Meaning |
|---|---|
| `id` | Stable observation identifier used for deduplication. |
| `market_id` | Stable identifier derived from the canonical market label. |
| `date` | Sale/report date in ISO `YYYY-MM-DD`. |
| `market` | Auction yard or reporting market. Regional reports use a regional report name. |
| `state`, `county` | Physical location of the reporting auction only when established. County may be null. |
| `geography_method` | How the reporting location was assigned; regional reports remain unassigned. |
| `sale_regionality` | Human-readable reporting sale location/region. This is not animal origin. |
| `animal_origin` | Source-stated animal origin only; null when not reported. |
| `corriente_origin` | `Native Corriente`, `Mexican M-branded Corriente`, `unspecified`, or `not_applicable`; native/M-branded require explicit source wording. |
| `weight_basis` | `reported_average`, `published_class_midpoint`, `published_class_range`, or `not_reported`. |
| `price_basis` | Distinguishes weighted averages, range midpoints, individual sale prices, lot highlights, video contracts, direct trades, and summaries. |
| `benchmark_key` | Canonical key that keeps category, unit, state, source type, and weight cohort separate. |
| `benchmark_weight_low`, `benchmark_weight_high` | Published weight-class bounds, or a 100 lb cohort around a reported average weight for $/cwt observations. |
| `category`, `sex`, `breed` | Animal class and source-described type. Unknown breed/type is not inferred. |
| `weight` | Reported average weight or representative class midpoint in pounds. When a class range is published, see `weight_low` / `weight_high`; the midpoint is only a filter/chart anchor, not an observed average. |
| `weight_low`, `weight_high` | Original published weight-class bounds in pounds, when supplied. |
| `price`, `price_low`, `price_high` | Reported price or midpoint and its published range. |
| `price_unit` | `USD/cwt`, `USD/head`, or `USD/family`; never compare unlike units. |
| `head` | Reported head count, or null if unavailable. |
| `record_type` | Sale/report method, such as auction average, published weight-class range, published price range, individual sale price, lot highlight, video contract, direct trade, or state summary. |
| `source`, `source_url` | Publisher and direct URL to the original report. |
| `qa_status`, `qa_warnings` | Collector validation outcome and non-fatal review flags. |

`published_individual_price` identifies a single published sale price (often breeding-stock lots) when the source does not provide a market weighted average or explicit range. It is benchmarked as a separate observation-mean series and is never pooled with auction weighted averages.

The QA report also includes `source_fetch_health` by domain: logical requests, attempts, successes, transient failures, final failed requests, failed URLs, and the most recent failure details. Network/timeouts, rate limits, and server errors are retried once; permanent 4xx errors are not retried. Historical quarantined observations remain in the QA report until a stable-ID record is accepted or a new rejection replaces the old reason.

## Interpretation rules

- Auction geography means the physical reporting yard, not the consignor's town, cattle origin, or destination.
- County attribution is null unless the auction's physical location is mapped. A multi-state/regional report must not be represented as a yard observation.
- Weights are pounds. Price units must be interpreted literally. For published weight-class ranges, `weight_low` and `weight_high` preserve the actual class; `weight` is the class midpoint used for simple filtering only, not a measured average.
- A published range is not a weighted average. A video contract is not a live auction result. A direct-trade report is not an auction-yard price. Benchmarks are never pooled across record types. Per-cwt records with reported average weights and no published class are placed into 100 lb cohorts; a published class is preserved exactly.
- Head weighting is allowed only when every included observation has a positive reported head count. If head counts are incomplete, every qualifying observation is included in an unweighted observation mean and the method is labelled.
- Cow-calf pairs use `USD/family`; bred cows and bred heifers use `USD/head`; feeder and per-cwt Corriente categories use `USD/cwt`. Unlike units are never converted or blended implicitly.
- Corriente origin is a separate classification dimension. Native, Mexican M-branded, and unspecified must not be conflated. "Fresh Corriente" is a sale description, not an origin.
- Records with an unclassifiable `Other` category or unknown animal sex are quarantined rather than published as usable market observations. Corriente lots with unknown sex remain in `Corriente cattle (unclassified)` when the source explicitly identifies Corriente.
- Null means not reported / not established, not zero.
- The dataset contains public market observations only. Do not add personal consignor or buyer details.
